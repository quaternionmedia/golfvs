# Code of Conduct

This project follows the [Contributor Covenant, version 2.1][cc]. The short
version, which is the whole of it in practice:

**Be decent.** Assume the person you are replying to is trying to make the thing
better. Disagree about the work, not about the person doing it. Harassment,
personal attacks, and unwelcome attention are not tolerated in issues, pull
requests, commits, or anywhere else this project happens.

**Kind comedy is a design pillar here** (Pillar 6, `DESIGN.md` §1) — the
defenders are rivals rather than villains and getting stopped is meant to be
funny rather than punishing. It would be strange to hold the game to that and
not the people making it.

**The game is for all ages.** Keep the repository that way too.

## Reporting

Report conduct concerns to the repository owner through GitHub — a direct
message, or a private vulnerability report if it needs to stay confidential and
there is no other private channel. Reports are handled by the maintainers, who
will keep the reporter's identity confidential.

Maintainers who do not follow or enforce this in good faith may face
consequences decided by the project's other maintainers.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
